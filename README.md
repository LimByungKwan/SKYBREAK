# SKYBREAK — 다섯 개의 하늘

「내가 설계한 미니게임」 과제로 제작한 브라우저 2D 비행 슈팅 게임입니다. 드래곤 플라이트와 오락실 비행 슈팅에서 플레이 아이디어를 얻고, 직접 만든 도형 그래픽·5종 보스·필살기로 구성했습니다. 원작의 이미지·음악·캐릭터 에셋은 사용하지 않았습니다.

- **게임 실행:** https://skybreak-five-20261014.quannie70.chatgpt.site
- **소스 저장소:** https://github.com/LimByungKwan/SKYBREAK

## 5스테이지와 보스

각 스테이지 시작 10초 후 보스가 등장합니다. 보스 이름·체력바·남은 체력은 플레이 화면 상단에 표시됩니다. 다음 스테이지 진입 시 체력 1칸을 회복하며 최대 체력은 5입니다.

|---:|---|---|---:|---|
|1|산악 계곡|스카이 가디언|110|부채꼴·원형 폭풍|
|2|사막 회랑|듄 스팅어|145|조준 탄환·양쪽 협공|
|3|거대 빙산|프로스트 레이|180|원형 탄막 필살기|

|5|우주 균열·요새|보이드 드래곤|370|드래곤 외형·이중 탄막/추적 공격·체력 절반 이하 폭주|

보스 필살기는 붉은 경고 후 발동하며 최종 보스를 격파하면 클리어합니다.

## 필살기·드랍 아이템

플레이어 필살기는 적 탄환과 일반 적 제거, 보스 피해 45, 2초 무적을 제공합니다. 게이지는 초당 5% 충전됩니다.

|항목|최종 설정|
|---|---|
|일반 적 드랍|10%|
|보스 드랍|50%|
|드랍 종류|공격력/실드 각각 50%|
|공격력 A|새로 발사하는 탄환 피해 5초간 1.3배, 재획득 시 5초 갱신|
|실드 S|다음 피해 1회 차단, 최대 1회|
|획득|떨어지는 아이템에 접촉|

아이템·버프·실드는 스테이지 전환 시 이어지며 새 판에는 초기화됩니다. 버프는 필살기 피해를 변경하지 않습니다.

## 직접 판단한 설계와 수정 과정

1. 5스테이지·단계별 보스·강한 최종 보스·양측 필살기를 선택했습니다.
2. 꾹 누른 방향키가 갑자기 빨라지는 문제를 플레이 중 발견했습니다. 반복 키 이벤트와 프레임 이동의 중복을 제거해 일정한 속도로 수정했습니다.
3. 보스 체력 UI를 플레이 화면 안으로 옮기고 단계별 배경을 강화했습니다.
4. 일반 적 드랍을 30%→15%→10%, 보스 드랍을 80%→50%로 줄이고 공격 버프를 8초·2배→5초·1.3배로 조정했습니다. 이 조정은 카드 3의 비교 전에 끝냈습니다.
5. 카드 3에서는 일반 적 탄환 기본 속도 한 값만 125→110px/초로 바꾸고 실제 10회씩 비교했습니다.

## 카드 5 — 효과·선택권·안전

충돌·보스 필살기·플레이어 필살기에 짧은 섬광을 제공합니다. 플레이어 필살기는 세로 광선도 표시합니다. 사운드는 없습니다.

효과 줄이기를 켜면 섬광·광선과 배경 시차 이동을 줄입니다. 체크 변경 시 진행 중인 섬광·광선을 즉시 종료하도록 구현했습니다. 공격 판정·탄환 제거·게이지 소모는 유지합니다.

- 사용자 캡처에서 필살기 효과 꺼짐/켜짐 차이와 게이지 소모를 확인했습니다.
- 사용자가 충돌 사건의 효과 비교와 효과 도중 체크 시 즉시 종료를 직접 확인하고 정상이라고 보고했습니다. 필살기 켜짐/줄이기 차이는 캡처, 즉시 종료는 사용자 직접 검사 결과를 근거로 구분해 기록합니다.
- 공개 HTML/CSS/JS와 소스 ZIP을 정적 검사해 실명·연락처·메일·API 키·토큰·비밀번호 원문을 발견하지 않았습니다. 로컬 점수·설정은 서버로 보내지 않습니다.

## 재현·통과 확인 4줄

1. **위치:** 공개 게임 URL의 30초 도전 모드와 게임 하단 다시 시작 버튼.
2. **행동:** 30초 도전 클릭 → 방향키로 30초 생존 시도 → 종료 후 다시 시작 클릭.
3. **통과:** 30초 생존에 성공, 체력 0에 실패 표시. 재시작 시 체력 5·점수 0·시간 0초 부근·게이지 100%로 초기화됩니다.
4. **안 될 때:** 체력 소진에는 실패 원인이 표시됩니다. 버튼 무반응·진행 중 시간 멈춤·재시작 후 이전 값 잔존은 기능 검사 실패입니다.

1. **AI에게 맡긴 일:** 게임 코드·원본 도형 그래픽·5종 보스·필살기·아이템 구현과 검사 코드·기록 정리.
